# E-Commerce Sales and Customer Analytics

## Project Overview
This project analyzes e-commerce sales and customer data using Power BI to understand sales performance, customer behavior, and business trends.

## Objectives
- Analyze total sales and profit
- Understand customer purchasing behavior
- Identify top-performing products and categories
- Analyze sales trends over time
- Create interactive Power BI dashboards

## Tools Used
- Power BI
- Power Query
- DAX
- Excel / CSV

## Key Analysis
- Sales and profit analysis
- Customer analysis
- Product and category performance
- Time-based sales trends
- Regional analysis

## Dashboard
The project includes an interactive Power BI dashboard with charts, KPIs, filters, and visualizations.
